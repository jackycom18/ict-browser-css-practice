# 码道内置浏览器精准调整 Web 页面设计

> 目标判据：华为 ICT 1.5 实验手册和用户“只使用免费资源”的约束。

## 目标

交付一份精致、响应式的宠物商店页面，并用元素级评论映射记录四次局部样式调整。页面主体保持黑、白、暖灰的编辑感基调，通过珊瑚红行动按钮、搜索焦点、商品卡和护理卡的局部反馈展示“精准选区 + CSS 双向编辑”。

## 元素级调整

1. 主行动按钮：选中 `.btn-primary`，把 Action Blue 改成珊瑚红 `#e5483f`，所有主要 CTA 同步更新。
2. 搜索框：选中 `.search__input`，增加珊瑚红 2px 焦点边框与柔和外光。
3. 商品卡：选中 `.card`，悬停时轻微上移并显示珊瑚红顶边，提供明确的可选反馈。
4. 护理卡：选中 `.care__item`，增加左侧珊瑚红强调线，表达服务层级但不改变布局。

## 页面结构

- 顶部全局导航与次级导航
- Hero、狗狗、猫咪、鸟类、小宠、商品和护理区块
- 纯 SVG 宠物插画和商品图标，不依赖外部图片
- 响应式导航在窄屏下折叠为菜单按钮

## 文件结构

- `index.html`：语义结构和内联 SVG。
- `styles.css`：设计令牌、组件、目标元素局部修改和响应式规则。
- `script.js`：移动端导航开关。
- `test-ui.py`：浏览器验收四项局部改动、菜单交互和外部资源检查。
- `README.md`：实验步骤映射、运行和验证。
- `docs/PROJECT_MEMO.md`、`docs/CODE_MAP.md`：交接文档。

## 验证

- 标题和主要内容正常渲染。
- 主按钮背景为珊瑚红。
- 搜索框聚焦后边框为珊瑚红。
- 商品卡和护理卡具有对应的目标样式。
- 移动端菜单可展开与关闭。
- 页面不请求 Google Fonts 或其他外部静态资源。
